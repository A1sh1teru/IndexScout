Что такое ScoutIndex

ScoutIndex — платформа для оценки футболистов по статистике РуСтат. Она отвечает на два вопроса: насколько игрок хорош в конкретной роли (стоппер, распасовщик, таргетмен…) и кого из другой лиги стоит взять, с поправкой на силу и стиль этой лиги.

Идея проста: сырые цифры («1,8 отбора за 90 минут») мало о чём говорят, пока их не с чем сравнить. Платформа сравнивает каждого игрока с конкурентами по амплуа и переводит каждый показатель в перцентиль — место в очереди от 0 до 99. Из перцентилей, взвешенных по важности, собираются индексы ролей — одно число, показывающее пригодность игрока к роли.

Все данные хранятся только в вашем браузере — ничего никуда не отправляется. Загруженные лиги и настройки переживают перезагрузку страницы.

Быстрый старт

  1. Откройте вкладку Данные и перетащите выгрузку РуСтат по своей лиге — CSV или Excel (конвертируется сам). Это будет основная лига, эталон для всех сравнений.
  2. На вкладке Игроки появится таблица с индексами ролей. Клик по строке — карточка игрока.
  3. Хотите искать усиление в других лигах — загрузите их выгрузки на вкладке Скаутинг и задайте каждой коэффициент силы.
  4. Понравившихся игроков собирайте в Списки кнопкой «+ В список» из карточки.

Перцентили и шкала

Перцентиль — положение игрока среди всех игроков его группы позиций по конкретному показателю:

  • 0 — худший в группе: не обходит никого;
  • 99 — лучший: обходит всех;
  • 50 — ровно середина лиги.

При одинаковых значениях игроки делят места и получают средний перцентиль связки. В расчёте участвуют только игроки, прошедшие порог минут (задаётся на «Данных»); остальные показаны серым и в рейтингах не участвуют.

Инвертированные метрики ⇩

Для потерь, фолов, ошибок и карточек действует правило «чем меньше — тем лучше»: перцентиль переворачивается (99 − значение). Такие метрики помечены стрелкой ⇩ в списках.

Цветовая шкала

Везде одна и та же логика: красный — плохо, жёлтый — средне, зелёный — отлично. Это стандарт FM/FBref — глаз быстро привыкает считывать таблицу по цвету.

Группы позиций

Игроки сравниваются только внутри своей группы позиций — нападающего не сравнивают с защитником по отборам. Позиция из файла РуСтат превращается в одну из шести групп:

Метрики, композиты, роли

Метрики

Это колонки выгрузки РуСтат: голы, передачи, единоборства… Всё уже пересчитано на 90 минут.

Составные метрики

Свои метрики из нескольких показателей. Пример: «Навесы» = перцентиль количества × 0,6 + перцентиль точности × 0,4 — так объём и качество сворачиваются в одно число. Создаются на вкладке «Роли и веса».

Роли

Роль — это набор метрик (сырых или составных) с весами важности. Индекс роли = сумма перцентилей × веса. Чем выше индекс, тем лучше игрок подходит под роль. Для каждой группы позиций — свои роли, все веса настраиваются под ваше видение футбола.

⚠ Если составная метрика называется так же, как сырая (например, «ТТД»), роль возьмёт составную. Давайте композитам отличимые имена — «ТТД (объём + качество)».

Вкладка «Игроки»

Рейтинг основной лиги по группам позиций. Что здесь есть:

  • Фильтры: поиск по имени/команде, выбор группы позиций и команды.
  • Индексы ролей — фиолетовый блок столбцов, по одному на каждую роль группы.
  • Средние разделов (Атака, Пас, Оборона…) — циановый блок: средний перцентиль всех метрик раздела.
  • Отдельные метрики — любой показатель можно вывести столбцом через панель «Столбцы таблицы»: показывается его перцентиль (в «Скаутинге» — с учётом коэффициента лиги, в шкале основной).

Клик по строке открывает карточку игрока.

Вкладка «Карточка»

Досье одного игрока:

  • Шапка: имя, флаг гражданства, команда, позиция и группа (можно сменить), возраст, рост, минуты. Рядом — средние перцентили по разделам и бейджи рекомендаций (для игроков скаут-лиг).
  • «+ В список» — добавление в лонг/шорт/вотч-листы, с созданием нового списка на месте.
  • Индексы ролей — полосы по каждой роли группы; для легионеров показано и «в своей лиге», и место в основной («топ-12%, №8 из 69»). Клик по роли переключает всё, что ниже.
  • Профиль роли — радар по метрикам выбранной роли. Можно наложить любого игрока основной лиги для сравнения (оба контура в одной шкале).
  • «На кого похож в основной лиге» — ближайшие по профилю выбранной роли игроки; смените роль — список пересчитается.
  • Все показатели на 90 минут — полный список метрик по разделам, значение + перцентиль. Метрики можно перетаскивать между разделами — средние разделов пересчитаются автоматически.

Вкладка «Скаутинг»

Поиск усиления в других лигах. Загрузите сколько угодно лиг — каждая получает:

При добавлении файла платформа спрашивает, какая это лига (список с поиском), и предлагает коэффициент по рейтингу Club Elo — медиане силы клубов высшего дивизиона. Предложение можно принять или поправить вручную.

  • Коэффициент силы относительно основной (основная = 1). Умножается каждый показатель игрока: 0,5 гола × 1,2 = 0,6 гола «в пересчёте на основную лигу». Больше 1 — лига сильнее вашей, меньше — слабее. Инвертированные метрики делятся. Процентные метрики пересчитываются через «шансы» успеха (85% → 85/15 × коэффициент → обратно в %) — так точность не обваливается от умножения и не выходит за 100%.
  • Свой порог минут — если сезон в той лиге короче; пусто = общий порог.

После пересчёта перцентили и индексы легионера считаются среди игроков основной лиги — как будто он уже играет у вас.

Стилевая нормализация (по медианам)

Лиги различаются стилем: в оборонительной лиге у всех больше единоборств. Включённая нормализация умножает показатель на отношение «медиана основной ÷ медиана его лиги» по каждой метрике внутри группы позиций — это убирает перекос стиля до применения коэффициента.

Кнопкой метрики: … рядом с галочкой можно выбрать, к каким метрикам она применяется. Смысл нормализация имеет для объёмных показателей; для знакопеременных (Голы-xG) и метрик с медианой около нуля множитель получается случайным — пресет «Рекомендуемые» отбирает подходящие автоматически. Если медиана любой из лиг ≤ 0, множитель к метрике не применяется в любом случае.

Уровни рекомендаций

  • ⭐ Звезда — лучшая роль игрока попадает в топ-N% основной лиги (порог настраивается);
  • 🟢 Усиление — в топ-25% (настраивается);
  • 🔵 Перспектива — возраст не старше порога, независимо от индекса.

В таблице это отдельный столбец с фильтром, а «Место в осн. лиге» показывает, куда игрок встал бы по своей лучшей роли.

Вкладка «Списки»

Ваши подборки игроков трёх типов: 📋 лонг-листы (широкий круг кандидатов), 🎯 шорт-листы (финальные цели), 👁 вотч-листы (наблюдение). Списков любого типа может быть сколько угодно, игрок может состоять в нескольких. Добавление — кнопкой «+ В список» в карточке (там же создаётся новый список), управление — пилюли, «Переименовать» и «Удалить» на самой вкладке. Клик по строке — карточка игрока.

Вкладка «Роли и веса»

Конструктор всей системы оценки:

  • Составные метрики — создание и редактирование композитов (части + веса).
  • Роли по группам позиций — состав и веса каждой роли. Бейдж Σ показывает сумму весов: веса не обязаны давать ровно 1 — при расчёте они нормализуются автоматически.
  • В длинных выпадающих списках метрик работает поиск — начните печатать.
  • Сохранить / загрузить настройки — весь конфиг (роли, композиты, пороги, столбцы) выгружается в JSON-файл и восстанавливается из него. Удобно для резервной копии и переноса.
  • Сброс к настройкам по умолчанию — вернуть стандартные роли.
Переименование составной метрики автоматически обновит все роли, где она используется; удаление — уберёт её из ролей. Если роль ссылается на несуществующую метрику, она помечается ⚠ и не участвует в расчёте.

Вкладка «Данные»

  • Основная лига — главная выгрузка РуСтат. Формат: CSV (разделитель «;») или Excel — платформа распознаёт и конвертирует сама. Обязательные колонки: «Игрок», «Позиция», «Минут на поле».
  • Минимум минут — общий порог участия в рейтингах (у скаут-лиг может быть свой).
  • Замена файла основной лиги пересчитывает всё; роли и настройки сохраняются.
  • Если набор колонок новой лиги отличается, платформа покажет «совпадает N из M метрик» — недостающие исключаются из ролей, их веса перераспределяются (⚠ в списке лиг и карточках).
  • Рыночные стоимости Transfermarkt подтягиваются автоматически из открытого датасета (файл tm_values.json, ~18 тыс. игроков из ~30 лиг): сопоставление по имени и возрасту, столбец «Стоимость» в таблицах, карточке и отчётах. Несопоставленные игроки показываются с «—»; в строке лиги видно «стоимости: N из M». Срез обновляется вместе с файлом.

Работа с таблицами

  • Сортировка — клик по заголовку, повторный клик меняет направление (▼/▲). Столбец «Рекомендация» сортирует по уровню: звёзды → усиление → перспектива → пустые.
  • Ширина столбцов — тяните фиолетовую полоску на границе заголовков (как в Excel). Двойной клик по полоске — вернуть ширину. Первый столбец с именем закреплён при прокрутке.
  • Панель «Столбцы таблицы» — галочки включают столбцы, перетаскивание чипов меняет порядок. Кнопка «+ Добавить метрику» открывает поиск по всем метрикам, сгруппированным по разделам; включённые метрики — чипы с ✕. В «Скаутинге» наборы столбцов можно сохранять и загружать.

Тонкости и FAQ

У бомбардира средний перцентиль по голам — почему?

Перцентиль считается внутри группы позиций. 0,4 гола за 90 минут — много для вингера из середины таблицы, но средне среди форвардов. Сначала проверьте, с кем именно его сравнивают.

Почему индекс роли не совпадает с перцентилем метрики?

Роль почти всегда состоит из нескольких метрик (или составных метрик — см. ⚠ выше про совпадающие имена), поэтому её индекс — взвешенная смесь, а не копия одного перцентиля.

Игрок серый, индексов нет

Не прошёл порог минут. Уменьшите общий порог на «Данных» или личный порог лиги в «Скаутинге».

Легионер с хорошей статистикой получил низкие индексы

Проверьте коэффициент его лиги: при 0,8 все его показатели урезаются на 20%, включая процентные. Коэффициент — ваша экспертная оценка силы лиги, подбирайте осознанно.

Где мои данные?

В хранилище браузера на этом компьютере (~5 МБ). Очистка данных сайта удалит лиги и настройки — поэтому периодически делайте «Сохранить настройки в файл» на «Ролях и весах». Выгрузки лиг храните в исходных файлах.

После обновления платформы что-то выглядит странно

Нажмите Ctrl+F5 — браузер подтянет свежую версию страницы.
